# 🚗 ADS Safety Platform - 系统介绍

## 项目概述

ADS Safety Platform（自动驾驶安全平台）是一个基于 **RSS（Responsibility Sensitive Safety）规则** 的实时异常检测系统，集成了 **CARLA 仿真器**进行自动驾驶车辆数据采集与安全验证。

本平台通过实时检测车辆的横向和纵向距离是否符合 RSS 安全标准，及时发现潜在的安全风险，并通过终端预警和 CARLA 可视化进行实时告警。

---

## 🎯 核心功能

### 1. RSS 安全规则检测

本平台严格复现了 Shalev-Shwartz 等人在 2017 年提出的 RSS（责任敏感安全）模型：

| 规则类型 | 论文依据 | 检测内容 |
|---------|---------|---------|
| **纵向安全距离** | §3.1 Longitudinal Model | 后车与前车的纵向距离是否满足最小安全距离 |
| **横向安全距离** | §3.2 Lateral Model | 相邻车道车辆的横向距离是否安全 |
| **交叉口优先权** | §4 Intersection Model | 交叉口场景下的路权分配与安全距离 |
| **行人安全** | §5 Pedestrian | 行人横穿马路时的安全距离 |

#### RSS 纵向安全距离公式

```
d_min = max(0, v_f * ρ + 0.5 * a_max * ρ² + (v_f + a_max * ρ)² / (2 * b_min) - v_l² / (2 * b_max))
```

参数说明：
- `v_f`: 后车速度 (m/s)
- `v_l`: 前车速度 (m/s)
- `ρ`: 反应时间 (0.5s)
- `a_max`: 后车最大加速 (2.0 m/s²)
- `b_min`: 后车最小制动 (4.0 m/s²)
- `b_max`: 前车最大制动 (8.0 m/s²)

### 2. 实时异常检测

系统能够检测以下类型的异常场景：

| 异常类型 | 描述 | 触发条件 |
|---------|------|---------|
| **急刹车** | 前车突然紧急制动 | 纵向距离 < d_min 且相对速度 > 0 |
| **近距离超车** | 车辆近距离变道超车 | 横向距离 < 安全阈值 |
| **快速接近** | 后车快速接近前车 | TTC < 3s |
| **尾随过近** | 长时间保持不安全车距 | 违规持续时间 > 1s |

### 3. 实时预警系统

#### 终端预警
- 🔴 **红色警告** (HIGH/CRITICAL): 紧急危险，需要立即采取措施
- 🟡 **黄色警告** (MEDIUM): 潜在风险，需要注意
- 🟢 **绿色信息** (SAFE): 安全状态

#### CARLA 可视化预警
- 车辆颜色实时变化反映风险等级
- 高风险车辆显示为红色
- 中等风险车辆显示为黄色
- 安全车辆显示为绿色

### 4. 知识图谱生成

系统能够自动从检测结果生成知识图谱，用于：
- 异常场景的关系分析
- 风险传播路径可视化
- 事故原因追溯

### 5. 风险指数计算

基于 Candela 等人 (2022) 的研究，系统提供连续的风险指数（Risk Index ∈ [0, 1]）：

| 风险等级 | 风险指数 | 含义 |
|---------|---------|------|
| SAFE | 0.0 - 0.2 | 完全安全 |
| LOW | 0.2 - 0.5 | 风险较低 |
| MEDIUM | 0.5 - 0.8 | 中等风险 |
| HIGH | 0.8 - 0.9 | 高风险 |
| CRITICAL | 0.9 - 1.0 | 极度危险 |

## 🔧 技术栈

### 后端
- **Python 3.8+**
- **FastAPI**: 高性能异步 Web 框架
- **CARLA 0.9.x**: 自动驾驶仿真器
- **NumPy**: 数值计算
- **SQLAlchemy**: ORM 数据库操作
- **Pydantic**: 数据验证

### 前端
- **React 18**: UI 框架
- **Ant Design 5**: 组件库
- **Recharts**: 图表可视化
- **Vite 4**: 构建工具

### 基础设施
- **Docker**: 容器化部署
- **Nginx**: 反向代理
- **SQLite/PostgreSQL**: 数据存储
