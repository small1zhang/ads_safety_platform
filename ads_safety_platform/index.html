🎯 本体层 (Ontology)

定义14种实体类型和42种关系类型，构建知识图谱的基础

  • 车辆、行人、交通设施等实体
  • 场景、行为、规则等关系
  • 跨层关联关系

📥 提取层 (Extraction)

CARLA数据提取与标准化，支持平面和嵌套格式

  • 车辆数据提取
  • 行人数据提取
  • 交通灯状态提取
  • 场景快照生成

🛡️ 规则层 (Rules)

基于RSS理论的完整安全规则集

  • 纵向安全规则
  • 横向安全规则
  • 交叉口规则 (RCPP算法)
  • 行人保护规则
  • 风险指数计算
  • 交通规则 (R1-R3)

from kg_core.extraction.pipeline import ExtractionPipeline
from kg_core.rules.generator import RuleGenerator
from kg_core.visualization import SceneVisualizer
# 初始化管道
pipeline = ExtractionPipeline()
rule_generator = RuleGenerator()
visualizer = SceneVisualizer()
# 处理一帧数据
processed_frame = pipeline.process_frame(frame_data)
violations = rule_generator.check_frame(processed_frame)
visualizer.render(frame_data, violations)

📚 应用案例

在各种场景中的实际应用

🚦

交叉口安全

RCPP算法

在复杂交叉口场景中，RCPP算法能够正确判断车辆优先权，避免碰撞，确保安全通过。

👥

行人保护

RSS扩展

检测行人横穿、接近等行为，及时提醒自动驾驶系统采取避让措施。

⚡

性能优化

并行计算

通过并行计算和缓存机制，将规则检测性能提升3-4倍，支持实时处理。

📊

风险评估

连续指数

实时计算连续风险指数，为决策系统提供量化的风险评估依据。

🎯

CARLA集成

数据适配

完整支持CARLA仿真数据格式，可直接用于仿真环境中的安全验证。

📝

可解释性

自然语言
